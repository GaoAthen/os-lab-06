# Вывод прав при маске (022/077)
~~~
(маска 0022)
gao@fedora:~$ stat -c '%a %n' new_default dir_default
644 new_default - rw-r-r--
755 dir_default - rwxr-xr-x

(маска 0077)
gao@fedora:~$ stat -c '%a %n' new_default dir_default
644 new_default - rw-r-r--
755 dir_default - rwxr-xr-x

[права никак не меняются]
~~~

# Расчёт 666 и 777
`666` - [rw-rw-rw]

`777` - [rwxrwxrwx]

# Почему у файлов нету x а у каталогов есть
Сделано это для безопасности, если бы у файлов по умолчанию было право x(исполнение), то любой файл скачанный из интернета в котором есть какой нибудь вирус, мгновенно заразил бы ваш пк
Для каталогов право x означает совсем другое, для файлов x это исполнение, для каталога x это право просто зайти в сам каталог

# Зачем ставить umask 077
Основная цель этой настройки — реализация принципа наименьших привилегий на уровне файловой системы
